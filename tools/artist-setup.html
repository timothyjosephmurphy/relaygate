Squarespace and WordPress notes

Squarespace currently requires Core, Plus or Advanced for JavaScript or iframe code blocks. A normal link is the fallback. WordPress.com permits iframe/custom-code features on supported paid plans with hosting features activated; it may require activating those features by installing a plugin. Self-hosted WordPress depends on the site’s roles, security settings and theme. Check your actual account before changing plans.
